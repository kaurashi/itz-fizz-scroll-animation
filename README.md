# ITZ FIZZ — Scroll-Driven Hero Animation

A modern scroll-driven hero section built as a frontend animation assignment. The project focuses on smooth GSAP animations, scroll-based interactions, and responsive UI.

## ✨ Features

* Responsive hero section
* Letter-spaced headline with entrance animation
* Animated impact statistics
* GSAP-powered intro animations
* ScrollTrigger-based animations
* Scroll-driven movement, scaling, and rotation
* Smooth visual transitions
* Responsive desktop and mobile layout

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* GSAP
* GSAP ScrollTrigger
* JavaScript
* HTML
* CSS

## 🎬 Animations

The hero section includes:

* Headline fade and movement on page load
* Staggered statistics entrance
* Scroll-based visual movement
* Scroll-based scaling and rotation
* Headline and subtitle scroll interaction
* Rotating background visual
* Smooth scrub-based scrolling

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project:

```bash
cd itz-fizz-scroll-animation
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
